两个版本都是相同的上位机软件和下位机固件，只是PCB布局不同。


早期版本是一块大的PCB的USB接口是pl2303，后期改成CH340G

2019版本的PCB是一大一小两块板，去掉了跳线，将ADC和DAC的Vref改成手工测量后写到mcu，调整了ADC/DAC测量通道，量程继电器控制位也修改了。
2019版陆续改过几种PCB布局，第一种是小板只有"MCU+USB"、大板带ADC/DAC和功率放大器；后来改成小板整合全部数字部分(MCU+USB+ADC/DAC+HC595)、大板仅做功率板。


因为各个版本的测量通道以及量程继电器控制位有修改，所以程序的配置参数也要根据PCB做修改！！！！
